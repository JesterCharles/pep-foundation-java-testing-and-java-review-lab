# Testing and Java Review — Code lab

Rescue an old order service whose tests came first: fix a billing bug, cache a price feed (checked with Mockito), repair a switch and a comparator, and modernize old idioms.

- **Edit:** `OrderService.java` and `FakePriceFeed.java` in `src/main/java/exercise/`. Each task is marked `TODO`.
- **Run the tests:** **Run Tests** in Exa Studio, or `mvn test` with JDK 17 and Maven. All 5 visible tests fail at first; every message starts with `Task N:`.
- **Done** when every visible test passes. **Submit** also runs held-out tests you can't see.
